# AI Image Generator – MERN Stack

An AI-powered image generation web application built using the **MERN stack**.  
Users can generate images from text prompts, explore a community gallery, and share their creations.

This project focuses on clean UI, reusable components, and real-world full-stack architecture.

---

## 🚀 Features

- 🧠 AI image generation from text prompts  
- 🖼️ Community gallery to explore shared images  
- 🔍 Search images by prompt or creator  
- ⬇️ Download generated images  
- ⚡ Responsive and modern UI  
- 🌐 REST API integration  

---

## 🛠️ Tech Stack

### Frontend
- React
- Tailwind CSS
- React Router
- JavaScript (ES6+)

### Backend
- Node.js
- Express.js
- MongoDB
- REST APIs

### Other Tools
- Git & GitHub
- Render (Backend Deployment)
- Vercel / Netlify (Frontend Deployment)

---

## 📸 Application Overview

1. Enter a creative text prompt  
2. Generate an AI-powered image  
3. Preview and download the image  
4. Share it with the community gallery  
5. Search and explore other creations
